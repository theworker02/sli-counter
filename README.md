Keep a local {good,bad} store. Subcommands: good, bad, and report (success ratio).

## Install

```bash
git clone https://github.com/theworker02/sli-counter.git
cd sli-counter
npm install -g .
```

Package version: **1.00** (`1.0.0`).

## Usage

```bash
sli-counter good
sli-counter bad
sli-counter report
```
