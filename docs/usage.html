sli-counter

Every flag, subcommand, and exit code. Same examples as the README.

Synopsis

sli-counter <good|bad|report>
Tip: sli-counter --help prints this text in the terminal. sli-counter --version prints 1.0.0.

Flags and arguments

Flag / argumentMeaning
-h, --helpPrint detailed usage and exit 0.
-v, --versionPrint 1.0.0 and exit 0.
goodIncrement good by 1 and persist.
badIncrement bad by 1 and persist.
reportPrint {good,bad,total,ratio}. ratio is null when total is 0.

Exit codes

CodeMeaning
0good, bad, or report succeeded.
1Unknown or missing subcommand.

Configuration

State file is `.sli-counter.json` in the current working directory: {"good":0,"bad":0}. Created on first bump.

Worked examples

Success path

sli-counter report
{"good":2,"bad":1,"total":3,"ratio":0.6666666666666666}

Failure path

sli-counter
usage: sli-counter <good|bad|report>

Exit code is 1.
