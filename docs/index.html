sli-counter

Maintain a {good,bad} file store and report the success ratio.

1.00 / 1.0.0 branch main MIT Node.js >= 18

Overview

A local SLI does not need Prometheus. sli-counter is a two-bucket counter you can bump from scripts and report from cron.

People tracking flaky jobs, workshop pass rates, or homelab probes without standing up metrics infra.

Install

Install globally from Git, or run with Node from a clone. There are no extra dependencies.

npm install -g git+https://github.com/theworker02/sli-counter.git
sli-counter --help
node src/cli.js --help

Usage

Synopsis: sli-counter <good|bad|report>

See the full CLI reference for every flag, exit code, and example.

sli-counter 1.00 (1.0.0)

Usage:
  sli-counter good
  sli-counter bad
  sli-counter report
  sli-counter --help
  sli-counter --version

Store: ./.sli-counter.json  {good, bad}

report.ratio = good / (good + bad), or null when total is 0.

Options:
  -h, --help       Show this help
  -v, --version    Print 1.0.0

Examples

Success

sli-counter report
{"good":2,"bad":1,"total":3,"ratio":0.6666666666666666}

Failure

sli-counter
usage: sli-counter <good|bad|report>

Exit code is 1.
