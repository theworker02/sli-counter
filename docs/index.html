sli-counter

Tiny local reliability counters with SLI ratios and optional SLO checks.

1.1.0JSRMITNode.js ≥ 18

Overview

Track good and bad events without deploying a metrics stack, then evaluate the current ratio against a target.

Structured API

Canonical package: @theworker02/sli-counter

import { bump, report } from "@theworker02/sli-counter";
bump("good");
console.log(report(undefined, undefined, { slo: 0.99 }));
