sli-counter

Good/bad SLI counter · version 1.00

Purpose

Keep a local {good,bad} store. Subcommands: good, bad, and report (success ratio).

Install

npm install -g sli-counter

Usage

sli-counter good
sli-counter bad
sli-counter report
